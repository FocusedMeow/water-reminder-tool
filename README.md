# 喝水提醒 · 离线网页版

一个不需要安装、不联网的单文件喝水提醒工具。

## 打开方式

双击 **`喝水提醒.html`**，用 Edge / Chrome / Firefox 打开即可。

建议把标签页固定（右键标签页 → 固定标签页），避免误关。

## 能做什么

- 默认每 45 分钟提醒一次，可调 10 分钟 – 2 小时
- 每日目标 8 杯 / 2000 毫升，杯数和每杯容量都能改
- 一个会随进度注水的玻璃杯 + 今日杯数、毫升数、连续达标天数
- 最近 7 天饮水记录，自动跨天归档
- 提醒卡、提示音、标签页标题闪烁，可选浏览器系统通知
- 「稍后 10 分钟」「暂停 1 小时」「预览提醒」
- 数据只存在本机浏览器，不上传、不联网

## 重要限制（请先看）

1. **必须保持这个标签页打开。** 浏览器关闭后，网页无法再提醒你。这是网页和桌面程序最大的区别。
2. **后台标签页的计时可能被浏览器降频。** 提醒可能比设定时间晚几十秒；回到页面会按时间立即补上。
3. **系统通知可能受浏览器限制。** 点页面里的「开启浏览器通知」并允许后，后台也能收到通知。如果从本地文件打开时浏览器不允许通知，页面内的提醒卡、提示音和标题闪烁仍然有效。
4. **提示音需要先点一下页面。** 浏览器的自动播放限制要求至少一次用户交互。
5. **记录保存在当前浏览器的 localStorage。** 清理浏览器数据、使用无痕模式或换浏览器，记录会丢失或不共享。

## 建议的使用方式

- 把页面固定在浏览器标签栏，或设为浏览器启动页。
- 第一次打开时可以点「预览提醒」，先看看提醒卡和声音的效果，不用等 45 分钟。
- 需要临时安静时点「暂停 1 小时」；想提前结束暂停，再点一次「继续」。
- 设置里的「提醒时段」开始时间等于结束时间时，表示全天提醒。

## 设置说明

右上角齿轮打开设置：

| 项目 | 说明 |
| --- | --- |
| 提醒间隔 | 10 分钟 – 2 小时 |
| 每日目标 | 1 – 30 杯 |
| 每杯容量 | 50 – 1000 毫升 |
| 提醒时段 | 默认 08:00 – 23:00 |
| 提示音 | 提醒时播放轻柔的双音 |
| 浏览器通知 | 需要用户授权，页面内提醒始终有效 |

设置底部还有「恢复默认」和「清空今日记录」。

## 数据与卸载

- 数据位置：当前浏览器的 localStorage（键名 `drinkwater.v1`），不上传。
- 卸载：删除 `喝水提醒.html` 即可；如需清除记录，在浏览器设置中清除该文件的站点数据。

## 旧版桌面程序（可选）

`旧版-桌面程序\DrinkWater.exe` 是之前的 Windows 托盘版：

- 关掉浏览器也能提醒，适合需要长期在后台运行的场景
- 支持开机自启、托盘菜单、系统通知
- 双击运行，右键托盘图标可设置

网页版更轻量、跨平台、无需安装；托盘版更适合「一定要提醒到」的场景。两者数据互不相通。
