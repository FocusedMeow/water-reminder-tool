# 源码说明

## 网页版（主版本）

**源码文件：`喝水提醒.html`**

这是一个单文件应用：HTML 结构、CSS 样式、JavaScript 逻辑全部在同一个文件里。

- 没有构建步骤
- 没有第三方库
- 没有任何网络请求
- 双击就能运行，复制到任何文件夹也能运行

### 查看和修改

1. 右键 `喝水提醒.html` → 打开方式 → 记事本 / VS Code / Sublime Text。
2. 修改后保存，回到浏览器按 `Ctrl + F5` 刷新即可。
3. 想改默认值，直接搜 `var DEFAULTS`。

### 默认设置

```js
var DEFAULTS = { interval: 45, target: 8, cupMl: 250, start: '08:00', end: '23:00', sound: true };
```

- `interval`：提醒间隔（分钟）
- `target`：每日目标杯数
- `cupMl`：每杯容量（毫升）
- `start` / `end`：提醒时段；两者相同表示全天
- `sound`：是否播放提示音

### 几个实现要点

- **计时不靠累加**：每次安排的是绝对时间 `nextAt`，刷新页面不会把 45 分钟重新开始。
- **跨天自动归档**：`ensureToday()` 把昨天的杯数写进 `history`，再重置今日数据。
- **7 天记录 / 连续达标**：都从 `history` 和今日杯数计算，不依赖后端。
- **提醒兜底**：浏览器通知是可选增强；页面内提醒卡、提示音、标签页标题闪烁始终可用。
- **数据存储**：只使用 `localStorage`，不上传任何内容。

### 想改哪里

- **颜色 / 圆角 / 字体**：CSS 开头的 `:root` 变量和 `.card`、`.btn` 等规则。
- **默认间隔 / 目标 / 时段**：`var DEFAULTS`（第 490 行）。
- **文案**：页面结构里的中文，以及 `render()`、`showReminder()` 里的提示语。
- **玻璃杯水位**：`updateGlass()` 里的 `232 - 190 * ratio` 控制水面高度。

## 旧版桌面版（可选）

**源码文件：`旧版-桌面程序/src/DrinkWater.cs`**

之前的 Windows 托盘程序，C# WinForms 单文件实现，和网页版没有依赖关系。

- 构建脚本：`旧版-桌面程序/build.ps1`
- 使用 .NET Framework 自带的 `csc.exe` 编译
- 功能：托盘图标、45 分钟提醒、开机自启、每日进度、设置窗口

网页版是现在的主版本；桌面版保留给「浏览器关掉也要提醒」的场景。
